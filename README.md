# PTI -  Desenvolvimento API REST

O projeto foi desenvolvido por Julio Caria, estudante de Tecnologia em Sistemas da Internet para entrega à Instituição Senac - Santo Amaro, com o objetivo de abordar conceitos ensinados na disciplina de Desenvolvimento de API REST. Sendo assim, abaixo estão listadas mais informações a respeito do enunciado, Stack utilizada, desenvolvimento da interface (UI), estrutura do banco de Dados e documentação da API.

## Enunciado

1. Definir um ramo de empresa juntamente com o schema da tabela de produto.

> **DETALHE:** A modelagem deve possuir uma única tabela

2. Implementar os endpoints que permitem o gerenciamento do catálogo de produtos, devem ser planejados como:
  - `POST`: /produto
  - `GET`: /produto?nome=
  - `PUT`: /produto:/id
  - `DELETE`: /produto:/id

## Stack

- Framework: Fastify - Documentação
- ORM: Sequelize - Documentação
- Documentação da API: Swagger - Documentação
